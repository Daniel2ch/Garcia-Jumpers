# Garcia-Jumpers

Garcia Jumpers is a React-based website built for a local business in Prosser, WA. The project showcases company information, product listings, and a responsive user interface with modern development tooling.

## Project description

This repository contains a small React application located in the `my-react-app` folder. The application is built with Vite and uses React 19.

Key features:
- Home page with featured products and business overview
- About page with company details and local business information
- Product modal component for viewing product details
- Responsive layout with a simple navigation bar

## Folder structure

- `my-react-app/` - main React application
- `my-react-app/src/` - source files including components and pages
- `my-react-app/components/` - reusable UI components such as `Navbar.jsx` and `ProductModal.jsx`
- `my-react-app/src/pages/` - page components such as `Home.jsx` and `About.jsx`
- `my-react-app/public/` - static public assets if needed

## Getting started

1. Open a terminal in the project root:

   cd my-react-app

2. Install dependencies:

   npm install

3. Start the development server:

   npm run dev

4. Open the application in your browser at the URL shown in the terminal, usually `http://localhost:5173`.
